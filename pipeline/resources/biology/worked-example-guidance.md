# Biology worked-example guidance

## Source pattern

SimpleStudy’s descriptive lessons use layered headings and note callouts; procedural topics need a
clearly sequenced investigation. Use SEC marking schemes for examinable reward points and create
all explanatory prose, datasets and experimental scenarios independently.

## Required answer shape

1. State the biological question or mechanism.
2. Name the relevant structures, substances or variables.
3. Explain the causal sequence or method in order.
4. Include control, measurement, repeats and safety where experimental.
5. Tie the conclusion directly to evidence.

## Original model

**Synthetic prompt:** Outline how to test whether temperature affects catalase activity.

**Model shape:** Prepare equal catalase and hydrogen-peroxide volumes at several controlled
temperatures, keeping concentration, pH and reaction time constant. Measure oxygen produced in the
same interval, repeat each temperature and compare mean rates. Wear eye protection and handle
peroxide carefully. A conclusion is supported only if the repeated mean rate changes systematically
with temperature; an anomalous tube should be reported rather than silently removed.
