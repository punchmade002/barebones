# DCG worked-example guidance

## Source pattern

SimpleStudy organises DCG into fine-grained constructions and explicitly named worked-example
topics. Follow the sequence, not the original diagrams or dimensions. SEC marking schemes govern
credit; every generated construction must be original and visually verified.

## Required answer shape

1. State the given views, dimensions and construction goal.
2. Select and justify the projection or locus method.
3. Number a reproducible construction sequence.
4. Apply correct line types, labels and intersections.
5. Verify alignment, true length/shape and geometric constraints on the final drawing.

## Original model

**Synthetic prompt:** Describe the method for finding the true length of a line shown foreshortened
in plan and elevation.

**Model shape:** Identify the endpoints in both views, introduce an auxiliary reference line
parallel to one projection of the line, project the endpoints perpendicular to that reference and
transfer their distances from the original complementary view. Join the auxiliary endpoints; this
auxiliary projection gives the true length. The generated diagram must confirm projector alignment.
