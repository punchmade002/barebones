# Mathematics worked-example guidance

## Source pattern

SimpleStudy’s quantitative lessons use layered sections followed by explicit question/solution
pairs and note callouts. Follow that teaching shape only. SEC papers and marking schemes control
exam style and credit; every example, value and solution must be independently generated.

## Required answer shape

1. State what must be found and select the method.
2. Write the relevant equation, identity or theorem.
3. Substitute accurately and show one transformation per line.
4. Preserve exact values until approximation is requested or useful.
5. Include units/domain restrictions and check the result in context.

## Original model

**Synthetic prompt:** Solve \(3(2x-5)=4x+7\).

**Model shape:**

\[
6x-15=4x+7
\]
\[
2x=22
\]
\[
x=11
\]

Check: \(3(22-5)=51\) and \(44+7=51\), so the solution satisfies the original equation.
