## Pipeline guidance

- Represent each item as a concept/skill node and separately record place examples, case studies,
  map skills and investigation skills.
- Build explanations as: process, named evidence/example, spatial pattern, consequence and
  evaluation where required.
- Map and photograph answers must cite visible evidence and location before inference.
- For case studies, generate a claim-evidence-link structure and verify statistics and dates from
  current primary sources.
- Generate original explanations; do not reproduce SimpleStudy prose or answers.
