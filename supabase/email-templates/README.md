# Supabase email templates

Generated by `scripts/build_email_templates.py`; edit the script, not these files.

Paste each file into **Supabase → Authentication → Emails → Templates**, using
the matching template and subject below. The `{{ ... }}` parts are Supabase
template variables and must stay as they are.

| Supabase template | File | Subject |
|---|---|---|
| Confirm signup | `confirm-signup.html` | Confirm your email, one click and you're in |
| Reset password | `reset-password.html` | Reset your barebones password |
| Magic link | `magic-link.html` | Your barebones sign-in link |
| Change email address | `change-email.html` | Confirm your new email for barebones |
| Invite user | `invite-user.html` | You're invited to barebones |
| Reauthentication | `reauthentication.html` | Your barebones confirmation code |
