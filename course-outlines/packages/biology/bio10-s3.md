## 1. Must cover

What the genetic code is (one block)
- [ ] G1 The genetic code is the set of rules by which the sequence of bases in DNA (copied into mRNA) is converted into the sequence of amino acids in a protein.
- [ ] G2 The code is read in groups of three bases. A codon is a sequence of three bases on mRNA that codes for one amino acid (or a stop signal). The matching three bases on DNA are called a triplet; some textbooks call these codons too.
- [ ] G3 Why three: there are 4 bases but about 20 amino acids. Reading one base at a time gives only 4 combinations and two at a time only 16 (4 × 4), not enough; three at a time gives 64 (4 × 4 × 4), more than enough.
- [ ] G4 Of the 64 codons, 61 code for amino acids and 3 are stop codons.
- [ ] G5 "Read by cellular machinery": the mRNA is read at a ribosome one codon at a time, and transfer RNA molecules bring the matching amino acids, which are joined in order. One bullet; the process belongs to "DNA Replication, Protein Synthesis and Mutations".

Features of the code (one block, one bullet per feature)
- [ ] F1 Start codon: AUG is the usual signal to start reading a gene's message, setting where the groups of three begin; it also codes for the amino acid methionine, so most new proteins begin with methionine.
- [ ] F2 Stop codons: UAA, UAG and UGA code for no amino acid; they signal the end of the protein, and the finished chain is released.
- [ ] F3 Non-overlapping and without gaps: the code is read three bases at a time from the start codon, each base belonging to only one codon, with no "commas" between codons. Adding or removing a single base therefore shifts every codon after it. (Frameshift mutations belong to "DNA Replication, Protein Synthesis and Mutations"; one phrase here.)
- [ ] F4 Degenerate (redundant): most amino acids have more than one codon, because 61 codons code for only 20 amino acids. Example: glycine is coded by GGU, GGC, GGA and GGG. Often only the third base differs, so some changes in a base still give the same amino acid.
- [ ] F5 Specific (unambiguous): each codon codes for only one amino acid.
- [ ] F6 Universal: almost all living things, from bacteria to plants and humans, use the same code, with a few minor exceptions (e.g. in mitochondria). This is evidence that all life shares a common ancestor, and it allows a human gene (e.g. for insulin) put into bacteria to be read correctly and make the human protein (detail in "Genetic Engineering").

Anticodons on tRNA (one block)
- [ ] A1 An anticodon is a sequence of three bases on a transfer RNA (tRNA) molecule that is complementary to an mRNA codon.
- [ ] A2 Each tRNA carries one specific amino acid, matching its anticodon. The anticodon pairs with the codon by complementary base pairing (A–U, C–G), so the right amino acid is brought for each codon. Example: the codon AUG pairs with the anticodon UAC, and that tRNA carries methionine.
- [ ] A3 No tRNA has an anticodon for a stop codon, so when a stop codon is reached no amino acid is added and the chain ends.
- [ ] A4 Diagram: a short strip of mRNA divided into codons (e.g. AUG | CCU | AAA), with tRNA molecules below, each showing its anticodon paired to a codon and its amino acid attached at the other end; label codon, anticodon, mRNA, tRNA, amino acid. Draw tRNA simply (a block or a T-shape); its cloverleaf structure belongs to "DNA Replication, Protein Synthesis and Mutations".

Decoding a sequence (one skills block, with the worked example)
- [ ] S1 Method: 1. write the mRNA complementary to the DNA strand being read (A → U, T → A, C → G, G → C); 2. split it into codons from the start codon; 3. find each amino acid in the codon table given in the question; 4. stop at a stop codon; 5. the anticodons are complementary to the codons. Students don't need to memorise the codon table except AUG and the three stop codons.
- [ ] S2 Worked example: DNA strand being read TAC GGA TTT ACT → mRNA AUG CCU AAA UGA → amino acids methionine, proline, lysine, then stop → tRNA anticodons UAC, GGA, UUU (none for UGA). Notice the anticodons have the same sequence as the DNA strand being read, with U in place of T.
- [ ] S3 Counting: each amino acid needs one codon of three bases, so a protein of 100 amino acids needs at least 300 bases of coding mRNA, plus three for the stop codon (303); a stretch of 90 coding bases codes for 30 amino acids.

Optional Nature of Science fact, only if used: in 1961 Marshall Nirenberg and Heinrich Matthaei showed that an artificial mRNA made only of uracil (UUU…) produced a chain of the amino acid phenylalanine, the first codon to be decoded. No other names, dates or codon assignments.

## 3. Traps

- Every block is Higher Level only; mark every heading. All key terms in this subsection (genetic code, codon, triplet, anticodon, start codon, stop codon, degenerate, universal) are Higher Level material.
- Codons are on mRNA; anticodons are on tRNA. Don't put anticodons on mRNA or on DNA.
- mRNA and tRNA contain uracil, never thymine; only the DNA sequence in S2 contains T.
- A codon codes for one amino acid, not one protein; a gene codes for a protein.
- Don't teach wobble pairing, reading frames on the "coding" vs "template" strand, RNA polymerase, ribosome binding sites, peptide-bond formation or the cloverleaf shape of tRNA. These belong to "DNA Replication, Protein Synthesis and Mutations" or are not on the specification. In S2 say "the DNA strand being read", not "template strand" or "antisense strand".
- Don't give codon assignments other than those in the checked-facts table; questions supply the table.
- The gene → protein → trait chain and its examples belong to "Genes, proteins and traits"; base-pairing rules belong to "Nucleotides, DNA and RNA". Use them without restating.
- Mutation types belong to "DNA Replication, Protein Synthesis and Mutations"; F3 and F4 mention their consequence in one phrase each.
- No other diagram cues beyond A4.

## 4. What exams ask (topics only)

- Define codon and anticodon; state where each is found.
- Explain why the genetic code must be a triplet code.
- Given a DNA or mRNA sequence and a codon table, give the mRNA, the anticodons and the amino-acid sequence.
- Explain the role of start and stop codons; explain what is meant by a universal or degenerate code.

## 5. Practice questions to write

1. 6 marks, Higher: "Distinguish between a codon and an anticodon." Model answer: G2 and A1 (three bases on mRNA coding for an amino acid vs three complementary bases on tRNA), with the AUG/UAC example from A2.
2. 9 marks, Higher: "Explain why the genetic code is described as a triplet code, and outline the role of start and stop codons." Model answer: G2–G3, F1–F2.
3. 12 marks, Higher: "A section of the DNA strand being read is TAC TTT GGA ATT. Using a codon table where AUG = methionine, AAA = lysine and CCU = proline, give the mRNA, the anticodons and the amino-acid sequence, and explain what happens at the last codon." Model answer: mRNA AUG AAA CCU UAA; anticodons UAC, UUU, GGA; methionine–lysine–proline; UAA is a stop codon with no matching tRNA, so the chain ends (S1, A3).
