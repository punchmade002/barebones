### 1. Must cover

The oxidation-number method (Higher Level only; one step per bullet)
- [ ] M1 [HL] Recap: oxidation is an increase in oxidation number and reduction a decrease; the rules for assigning them are in "Oxidation and reduction".
- [ ] M2 [HL] Step 1: assign oxidation numbers to every atom on both sides.
- [ ] M3 [HL] Step 2: identify the elements whose oxidation numbers change: one increases (the species containing it is oxidised, and is the reducing agent) and one decreases (that species is reduced, and is the oxidising agent).
- [ ] M4 [HL] Step 3: work out the change per formula unit (change per atom × number of those atoms in the formula), which equals the number of electrons lost or gained.
- [ ] M5 [HL] Step 4: choose coefficients for the oxidising and reducing agents (and their products) so that the total increase equals the total decrease (electrons lost = electrons gained); use the lowest common multiple.
- [ ] M6 [HL] Step 5: balance the remaining atoms by inspection, leaving oxygen and hydrogen until last (in acidic solution, add H₂O to balance O, then H⁺ to balance H).
- [ ] M7 [HL] Step 6: check that each element balances and that the total charge is the same on both sides.
- [ ] M8 [HL] Why: complex redox equations can't easily be balanced by inspection alone; matching electrons lost and gained fixes the key ratio first, and the charge check catches mistakes. Write every charge correctly: one wrong charge makes the equation wrong.

Example 1: manganate(VII) and iron(II) (Higher Level only; one step per bullet)
- [ ] F1 [HL] Unbalanced: MnO₄⁻ + Fe²⁺ + H⁺ → Mn²⁺ + Fe³⁺ + H₂O.
- [ ] F2 [HL] Oxidation numbers: Mn +7 → +2 (decrease of 5: reduced; MnO₄⁻ is the oxidising agent); Fe +2 → +3 (increase of 1: oxidised; Fe²⁺ is the reducing agent).
- [ ] F3 [HL] Equalise: one MnO₄⁻ gains 5 electrons, so 5 Fe²⁺ are needed: MnO₄⁻ + 5Fe²⁺ + H⁺ → Mn²⁺ + 5Fe³⁺ + H₂O.
- [ ] F4 [HL] Balance O: 4 O on the left, so 4H₂O on the right; balance H: 8 H in 4H₂O, so 8H⁺ on the left: MnO₄⁻ + 5Fe²⁺ + 8H⁺ → Mn²⁺ + 5Fe³⁺ + 4H₂O.
- [ ] F5 [HL] Check: Mn 1 = 1, Fe 5 = 5, O 4 = 4, H 8 = 8; charge left (−1) + 5(+2) + 8(+1) = +17; right (+2) + 5(+3) = +17.

Example 2: copper and dilute nitric acid (Higher Level only; one step per bullet)
- [ ] N1 [HL] Unbalanced: Cu + NO₃⁻ + H⁺ → Cu²⁺ + NO + H₂O.
- [ ] N2 [HL] Oxidation numbers: Cu 0 → +2 (increase of 2: oxidised; copper is the reducing agent); N +5 in NO₃⁻ → +2 in NO (decrease of 3: reduced; nitrate is the oxidising agent).
- [ ] N3 [HL] Lowest common multiple of 2 and 3 is 6: 3Cu (lose 6) and 2NO₃⁻ (gain 6): 3Cu + 2NO₃⁻ + H⁺ → 3Cu²⁺ + 2NO + H₂O.
- [ ] N4 [HL] Balance O: 6 O on the left, 2 in 2NO, so 4H₂O on the right; then 8 H means 8H⁺: 3Cu + 2NO₃⁻ + 8H⁺ → 3Cu²⁺ + 2NO + 4H₂O.
- [ ] N5 [HL] Check: charge left 2(−1) + 8(+1) = +6; right 3(+2) = +6.

Example 3: manganate(VII) and ethanedioate (oxalate) (Higher Level only; one step per bullet)
- [ ] X1 [HL] Unbalanced: MnO₄⁻ + C₂O₄²⁻ + H⁺ → Mn²⁺ + CO₂ + H₂O.
- [ ] X2 [HL] Oxidation numbers: Mn +7 → +2 (decrease of 5); C +3 in C₂O₄²⁻ (2C + 4(−2) = −2) → +4 in CO₂ (increase of 1 per C atom, so 2 per C₂O₄²⁻ ion).
- [ ] X3 [HL] Lowest common multiple of 5 and 2 is 10: 2MnO₄⁻ (gain 10) and 5C₂O₄²⁻ (lose 10), giving 2Mn²⁺ and 10CO₂.
- [ ] X4 [HL] Balance O: left 8 + 20 = 28; right 20 in 10CO₂, so 8H₂O; then 16H⁺: 2MnO₄⁻ + 5C₂O₄²⁻ + 16H⁺ → 2Mn²⁺ + 10CO₂ + 8H₂O.
- [ ] X5 [HL] Check: charge left 2(−1) + 5(−2) + 16(+1) = +4; right 2(+2) = +4.

Example 4: iodine and thiosulfate, a fractional oxidation number (Higher Level only; one step per bullet)
- [ ] T1 [HL] Unbalanced: I₂ + S₂O₃²⁻ → I⁻ + S₄O₆²⁻.
- [ ] T2 [HL] Oxidation numbers: I 0 → −1 (each I gains 1, so I₂ gains 2: reduced; iodine is the oxidising agent); S +2 in S₂O₃²⁻ → +2.5 in S₄O₆²⁻ (each S gains 0.5, so each S₂O₃²⁻ loses 1 electron: oxidised; thiosulfate is the reducing agent).
- [ ] T3 [HL] Two S₂O₃²⁻ ions lose 2 electrons, matching one I₂: I₂ + 2S₂O₃²⁻ → 2I⁻ + S₄O₆²⁻ (S₄O₆²⁻ is the tetrathionate ion).
- [ ] T4 [HL] Check: I 2 = 2, S 4 = 4, O 6 = 6; charge left 2(−2) = −4; right 2(−1) + (−2) = −4.

Example 5: phosphorus and nitrate, where one formula contains several atoms that change (Higher Level only; one step per bullet)
- [ ] P1 [HL] Unbalanced: P₄ + NO₃⁻ + H₂O → PO₄³⁻ + NO + H⁺.
- [ ] P2 [HL] Oxidation numbers: P 0 in P₄ → +5 in PO₄³⁻ (increase of 5 per atom, so 20 per P₄ molecule: oxidised; P₄ is the reducing agent); N +5 → +2 (decrease of 3: reduced; nitrate is the oxidising agent).
- [ ] P3 [HL] Lowest common multiple of 20 and 3 is 60: 3P₄ (lose 60) and 20NO₃⁻ (gain 60): 3P₄ + 20NO₃⁻ → 12PO₄³⁻ + 20NO.
- [ ] P4 [HL] Balance O: left 60, right 48 + 20 = 68, so 8H₂O on the left; then 16 H gives 16H⁺ on the right: 3P₄ + 20NO₃⁻ + 8H₂O → 12PO₄³⁻ + 20NO + 16H⁺.
- [ ] P5 [HL] Check: charge left 20(−1) = −20; right 12(−3) + 16(+1) = −20.

More equations to know (Higher Level only)
- [ ] Q1 [HL] Manganate(VII) oxidises chloride to chlorine (why hydrochloric acid is not used to acidify permanganate titrations): 2MnO₄⁻ + 10Cl⁻ + 16H⁺ → 2Mn²⁺ + 5Cl₂ + 8H₂O (Mn +7 → +2, gain 5; Cl −1 → 0, lose 1 each).
- [ ] Q2 [HL] Manganate(VII) oxidises iodide to iodine (used to make iodine for thiosulfate titrations): 2MnO₄⁻ + 10I⁻ + 16H⁺ → 2Mn²⁺ + 5I₂ + 8H₂O.
- [ ] Q3 [HL] Dichromate(VI) oxidises iron(II): Cr₂O₇²⁻ + 6Fe²⁺ + 14H⁺ → 2Cr³⁺ + 6Fe³⁺ + 7H₂O (each Cr +6 → +3, so Cr₂O₇²⁻ gains 6; each Fe²⁺ loses 1).
- [ ] Q4 [HL] Where only some atoms of an element change, count only those: in Cu + 2H₂SO₄ → CuSO₄ + SO₂ + 2H₂O, one S goes +6 → +4 (gain 2) and one stays +6 in CuSO₄; Cu loses 2; the second H₂SO₄ is needed to supply the sulfate.

Checking with half-equations (Higher Level only)
- [ ] H1 [HL] The same equation can be built from half-equations: balance the atom that changes, add H₂O to balance O, add H⁺ to balance H, then add electrons to balance charge; the number of electrons equals the change in oxidation number.
- [ ] H2 [HL] Example: MnO₄⁻ + 8H⁺ + 5e⁻ → Mn²⁺ + 4H₂O (5 electrons = the change from +7 to +2) and Fe²⁺ → Fe³⁺ + e⁻.
- [ ] H3 [HL] Multiply so the electrons cancel (the iron half-equation × 5) and add: MnO₄⁻ + 8H⁺ + 5Fe²⁺ → Mn²⁺ + 5Fe³⁺ + 4H₂O. Exam questions usually say "hence or otherwise", so either method earns the marks once oxidation numbers have been assigned.

### 3. Traps

- Multiply the change per atom by the number of atoms of that element in the formula (2 C in C₂O₄²⁻, 2 Cr in Cr₂O₇²⁻, 4 P in P₄, 2 I in I₂).
- Balance the electron change before adding H₂O and H⁺; adding them first leads to wrong ratios.
- Always check charge as well as atoms; an equation can balance in atoms and still be wrong.
- Spectator ions (K⁺, SO₄²⁻, Na⁺) are left out of ionic equations.
- Keep to compounds of the first 36 elements: past papers balanced an equation with bismuthate (BiO₃⁻; bismuth is element 83), which is outside the specification.
- The rules for assigning oxidation numbers belong in "Oxidation and reduction"; don't restate them.

### 4. What exams ask (topics only)

- Assign oxidation numbers and, hence or otherwise, balance a redox equation (e.g. MnO₄⁻ with Fe²⁺, Cl⁻, C₂O₄²⁻ or I⁻; P₄ with NO₃⁻; Cu with NO₃⁻).
- Show using oxidation numbers where oxidation and reduction take place; identify the reducing or oxidising agent.

### 5. Practice questions to write

1. 9 marks: "Using oxidation numbers, show which species is oxidised and which is reduced in MnO₄⁻ + Cl⁻ + H⁺ → Mn²⁺ + Cl₂ + H₂O. Hence balance the equation and identify the oxidising agent." Model answer: Mn +7 → +2 (reduced, gain 5); Cl −1 → 0 (oxidised, lose 1 per Cl, 2 per Cl₂); 2MnO₄⁻ + 10Cl⁻ + 16H⁺ → 2Mn²⁺ + 5Cl₂ + 8H₂O; charges +4 = +4; oxidising agent MnO₄⁻.
2. 9 marks: "Balance, using oxidation numbers, Cr₂O₇²⁻ + Fe²⁺ + H⁺ → Cr³⁺ + Fe³⁺ + H₂O, and identify the reducing agent." Model answer: Cr +6 → +3 (each Cr gains 3, Cr₂O₇²⁻ gains 6); Fe +2 → +3 (loses 1), so 6Fe²⁺; 7 O → 7H₂O; 14H⁺; Cr₂O₇²⁻ + 6Fe²⁺ + 14H⁺ → 2Cr³⁺ + 6Fe³⁺ + 7H₂O; charges +24 = +24; reducing agent Fe²⁺.
3. 9 marks: "Hydrogen peroxide is oxidised to oxygen by acidified potassium manganate(VII): MnO₄⁻ + H₂O₂ + H⁺ → Mn²⁺ + O₂ + H₂O. Assign oxidation numbers to manganese and to the oxygen in H₂O₂ and O₂, and balance the equation." Model answer: Mn +7 → +2 (gain 5); O −1 in H₂O₂ (peroxide) → 0 in O₂ (each O loses 1, so each H₂O₂ loses 2); LCM 10: 2MnO₄⁻ and 5H₂O₂ giving 2Mn²⁺ and 5O₂; the 8 O from 2MnO₄⁻ (still −2) form 8H₂O; H: 16 needed, 10 from 5H₂O₂, so 6H⁺; 2MnO₄⁻ + 5H₂O₂ + 6H⁺ → 2Mn²⁺ + 5O₂ + 8H₂O; charges +4 = +4. ### 1. Must cover

The electrochemical series (one block)
- [ ] S1 The electrochemical series is a list of metals (and hydrogen) in order of their tendency to be oxidised, that is, to lose electrons and form positive ions in solution.
- [ ] S2 Order (most easily oxidised first): potassium, calcium, sodium, magnesium, aluminium, zinc, iron, lead, hydrogen, copper, silver, gold (K, Ca, Na, Mg, Al, Zn, Fe, Pb, H, Cu, Ag, Au).
- [ ] S3 A metal high in the series loses electrons easily (M → Mⁿ⁺ + ne⁻), so it is a strong reducing agent; e.g. Mg(s) → Mg²⁺(aq) + 2e⁻ happens more readily than Cu(s) → Cu²⁺(aq) + 2e⁻.
- [ ] S4 The ions of metals low in the series gain electrons most easily, so they are the better oxidising agents (e.g. Ag⁺ and Cu²⁺ are reduced more readily than Mg²⁺ or Zn²⁺).
- [ ] S5 Metals near the top corrode most easily; gold and silver at the bottom are found uncombined in nature and resist corrosion, which is why they are used in jewellery.
- [ ] S6 Hydrogen is included as a reference point: metals above hydrogen displace it from dilute acids (e.g. Mg(s) + 2H⁺(aq) → Mg²⁺(aq) + H₂(g)); copper, silver and gold, below hydrogen, don't react with dilute hydrochloric or sulfuric acid (see "Acids, bases and their reactions").

Displacement reactions (one block)
- [ ] D1 A displacement reaction of metals: a metal higher in the series displaces a metal lower in the series from a solution of its ions. The higher metal is oxidised (reducing agent); the lower metal's ions are reduced (oxidising agent).
- [ ] D2 Zinc in copper(II) sulfate: Zn(s) + Cu²⁺(aq) → Zn²⁺(aq) + Cu(s); half-equations Zn → Zn²⁺ + 2e⁻ and Cu²⁺ + 2e⁻ → Cu. The grey zinc becomes coated with brown copper and the blue colour fades.
- [ ] D3 Magnesium in copper(II) sulfate: Mg(s) + Cu²⁺(aq) → Mg²⁺(aq) + Cu(s); brown copper forms, the blue colour fades and the solution warms (the reaction is exothermic).
- [ ] D4 Iron in copper(II) sulfate: Fe(s) + Cu²⁺(aq) → Fe²⁺(aq) + Cu(s); an iron nail becomes coated with pink-brown copper and the solution turns from blue towards pale green (iron(II) ions).
- [ ] D5 Copper in silver nitrate: Cu(s) + 2Ag⁺(aq) → Cu²⁺(aq) + 2Ag(s); grey-white crystals of silver grow on the copper and the colourless solution turns blue (copper(II) ions).
- [ ] D6 No reaction when the metal is lower than the metal ion: copper in zinc sulfate, or copper in sodium chloride solution (Cu + 2Na⁺ → Cu²⁺ + 2Na does not happen, because copper is below sodium and is less easily oxidised).
- [ ] D7 The anions (e.g. SO₄²⁻, NO₃⁻) don't change; they are spectator ions and are left out of the ionic equation.
- [ ] D8 The further apart two metals are in the series, the more vigorous the displacement reaction tends to be (e.g. magnesium with copper(II) ions reacts faster and releases more heat than iron with copper(II) ions).

Investigation: aim, variables and method (one block, one step per bullet)
- [ ] I1 Aim: to place magnesium, zinc, iron and copper in order of their tendency to be oxidised, using displacement reactions, and to compare the order with the electrochemical series.
- [ ] I2 Variables: independent, the metal (and the metal-ion solution); dependent, whether a reaction is seen (deposit, colour change, temperature rise); controlled, the concentration and volume of each solution, the size and surface area of each metal piece, the temperature and the time allowed.
- [ ] I3 Clean each strip of metal (magnesium ribbon, zinc foil, iron nail or wire, copper foil) with sandpaper to remove the oxide layer, which would stop or slow the reaction.
- [ ] I4 Place the same volume (e.g. about 5 cm³) of each solution, all at the same concentration, in test tubes (or the wells of a spotting tile): magnesium sulfate, zinc sulfate, iron(II) sulfate and copper(II) sulfate.
- [ ] I5 Add a piece of each metal to each solution other than its own; a metal in a solution of its own ions acts as a control (no reaction possible).
- [ ] I6 Leave for a set time (e.g. 5 minutes) and record any deposit on the metal, change in colour of the solution and temperature change in a results grid; repeat to check the observations.

Investigation: results and conclusion (one block)
- [ ] R1 Sample results (expected): magnesium reacts with zinc, iron(II) and copper(II) ions (3 reactions); zinc reacts with iron(II) and copper(II) ions (2); iron reacts with copper(II) ions (1); copper reacts with none (0).
- [ ] R2 Ranking by number of displacements gives Mg > Zn > Fe > Cu, which matches the order in the electrochemical series: magnesium is the most easily oxidised and the strongest reducing agent of the four.
- [ ] R3 Write an ionic equation for each reaction seen, e.g. Mg(s) + Zn²⁺(aq) → Mg²⁺(aq) + Zn(s) (grey zinc deposit on the magnesium); Zn(s) + Fe²⁺(aq) → Zn²⁺(aq) + Fe(s) (dark deposit; the pale green colour fades).
- [ ] R4 A larger temperature rise (measured with a thermometer, using equal amounts of metal powder and solution) is further evidence that the metals are further apart in the series.
- [ ] R5 Limitation: no visible change shows that any reaction is too slow to see in the time allowed; it doesn't prove that no reaction is possible.

Safety and sources of error (one block)
- [ ] H1 Wear goggles; copper(II) sulfate is harmful if swallowed and an irritant; silver nitrate stains skin and is corrosive; collect metal-ion solutions in a waste container rather than pouring them down the sink (they are harmful to aquatic life); keep magnesium away from flames.
- [ ] H2 Errors: an oxide layer left on a metal (especially aluminium, whose Al₂O₃ layer makes it appear unreactive) can stop a reaction that should happen; deposits are hard to see on dark metals; very slow reactions may be missed; different surface areas or concentrations make comparisons unfair.
- [ ] H3 Diagram: a row of test tubes in a rack (or a spotting tile), each containing a metal-ion solution with a strip of metal, labelled with the metal and the solution; a results grid of metals against solutions with ticks and crosses.

Using secondary data (one block)
- [ ] U1 Secondary data are results collected by others (e.g. a table of displacement observations from another class or a data source); they are analysed in the same way: a metal that displaces another from solution is higher in the series.
- [ ] U2 Example: if metal X displaces copper and lead from solutions of their ions but not zinc, X lies between zinc and lead in the series.
- [ ] U3 The series can be used to predict reactions without doing them: e.g. zinc will displace silver from silver nitrate; silver will not displace copper from copper(II) sulfate.
- [ ] U4 The most reactive metals (potassium, sodium, calcium) are not used in displacement from solution: they react with the water instead (2Na + 2H₂O → 2NaOH + H₂), releasing hydrogen.

### 3. Traps

- The series is about metals losing electrons (oxidation); a metal high in the series is a strong reducing agent, not a strong oxidising agent.
- Displacement needs the solid metal to be higher than the metal in the ion; a metal never displaces a more reactive metal.
- Don't use K, Na or Ca to displace metals from solution: they react with water.
- Aluminium's oxide layer can hide its true position; clean it or note this as a limitation.
- Standard electrode potentials are not mentioned in the specification; use the series as an ordered list only.
- Corrosion protection belongs to "Oxidation and reduction"; electrochemical cells belong to "Galvanic and electrolytic cells".

### 4. What exams ask (topics only)

- Describe what is observed when zinc or magnesium is added to copper(II) sulfate solution; write the ionic equation.
- Which metal is more easily oxidised, and so higher in the electrochemical series; justify using an observation.
- Will a given displacement occur (e.g. copper in sodium chloride solution)? Explain.
- Relative reducing abilities of metals from displacement observations.

### 5. Practice questions to write

1. 9 marks: "Describe an investigation to place magnesium, zinc, iron and copper in order of their tendency to be oxidised, using displacement reactions. State how the results relate to the electrochemical series." Model answer: I2, I3–I6, R1, R2.
2. 6 marks: "Magnesium ribbon is added to copper(II) sulfate solution. State two observations, write a balanced ionic equation, and identify the reducing agent." Model answer: D3 observations (brown copper forms; blue colour fades; solution warms); Mg(s) + Cu²⁺(aq) → Mg²⁺(aq) + Cu(s); magnesium is the reducing agent.
3. 6 marks: "Equal masses of magnesium and zinc powder were added to equal volumes of the same copper(II) sulfate solution. The blue colour disappeared completely with magnesium but only faded with zinc. Suggest two reasons."
