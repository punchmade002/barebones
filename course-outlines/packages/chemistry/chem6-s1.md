# Package: chem6-s1 — Electronegativity and bond type

- **loId:** `chem6-s1` · **chapterId:** `chem6` · **syllabusRef:** 2.1.2
- **Syllabus:** 2.1.2 "predict the nature of chemical bonds between atoms, using trends in
  electronegativity values". Learn about: "how the concept of electronegativity, and explaining
  trends in electronegativity values, can be used to predict the nature of the chemical bond
  along the continuum". Normal type. 1.3 also names "electronegativity (using Pauling scale)".
- **Prepared by:** a higher model, 2026-10-30. Definition, Pauling values, trends with
  explanation, and predicting bond type from the difference. The continuum itself is introduced
  in "Types of chemical bonding"; refer to it.

## 1. Must cover

Electronegativity (one block)
- [ ] E1 Electronegativity is the relative attraction that an atom in a molecule has for the shared pair of electrons in a covalent bond.
- [ ] E2 It is measured on the Pauling scale, on which fluorine, the most electronegative element, has the highest value (3.98, about 4); the values have no units.
- [ ] E3 Values to use (Pauling scale): F 3.98; O 3.44; Cl 3.16; N 3.04; Br 2.96; I 2.66; S 2.58; C 2.55; H 2.20; P 2.19; Si 1.90; Al 1.61; Mg 1.31; Ca 1.00; Li 0.98; Na 0.93; K 0.82.
- [ ] E4 Non-metals have high electronegativities; metals have low ones.

Trends and their explanation (one block)
- [ ] T1 Across a period (left to right) electronegativity increases, e.g. Na 0.93 → Cl 3.16.
- [ ] T2 Explanation across a period: the nuclear charge increases while electrons are added to the same main energy level, so the atomic radius decreases and the nucleus attracts bonding electrons more strongly.
- [ ] T3 Down a group electronegativity decreases, e.g. F 3.98 → I 2.66.
- [ ] T4 Explanation down a group: each element has an extra energy level, so the atomic radius increases and the inner electrons screen (shield) the outer electrons from the nucleus; the bonding electrons are further away and less strongly attracted, even though the nuclear charge is greater.
- [ ] T5 Noble gases are usually given no electronegativity value because they rarely form bonds.

Predicting bond type (one block, skills)
- [ ] P1 Find the difference in electronegativity between the two atoms; the larger the difference, the more ionic the bond.
- [ ] P2 Difference greater than 1.7: mainly ionic, e.g. NaCl: 3.16 − 0.93 = 2.23.
- [ ] P3 Difference between about 0.4 and 1.7: polar covalent, e.g. H–Cl: 3.16 − 2.20 = 0.96; O–H: 3.44 − 2.20 = 1.24.
- [ ] P4 Difference less than about 0.4: non-polar (pure) covalent, e.g. C–H: 2.55 − 2.20 = 0.35; Cl–Cl: 0.
- [ ] P5 The more electronegative atom carries the partial negative charge (δ−) in a polar bond.
- [ ] P6 These cut-offs are guides, not sharp boundaries, because bonding is a continuum.

## 3. Traps

- Electronegativity is for an atom in a bond; it is not the same as ionisation energy (taught in "Ionisation energies and atomic radii").
- Don't give older rounded values (e.g. O 3.5, C 2.5) alongside these; use one set.
- Bond-type properties belong to "Bonding and properties".

## 4. What exams ask (topics only)

- Define electronegativity; explain the trends across a period and down a group.
- Use electronegativity values to predict the type of bond in given compounds; identify the δ− atom.
